Make the tune

Listen to the tune. Then set the table so one wave plays it, note for note, and press play.

  • an arrow: tap to turn it
  • a dial: tap to tune it
  • corners: drag it somewhere else
  • nothing: it stays as it is

Tap any instrument to hear its note. Drums bounce the wave and keep time; they are not the tune. A wave running along a string holds one note.
